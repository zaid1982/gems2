6a. Dense workbook — 32px cells, not the 38px contract

Application forms, filters, modals and DataTables toolbars stay on --gems-control-h (38px). A dense HTML workbook (Energy Daily / BEI, and later PTW/PPM grids that look the same) may use the existing Energy helpers: .enr-grid + .enr-grid-wrap for a sticky-header grid, or .bei-table for a card-table workbook. Cell .form-control inputs become 32px. Reuse those selectors. Do not invent a second 32px class, and do not change the default 38px system.

Use 32px workbook cells when The surface is an HTML table of many inline numeric cells (a month of daily readings, a 12-month BEI sheet). Horizontal scroll stays inside .enr-grid-wrap or .table-responsive. Row actions stay .gems-btn-action (already 32px).
Do not use 32px when The control is a page filter, modal field, gems-form-grid sheet, DataTables toolbar, or any ordinary form. Those stay 38px. Do not set a one-off height: 32px on a page. Do not apply .enr-grid to a DataTable.

10. Close-up QA — run this on every converted page

A screenshot of the whole page is not “done”. Check each screen in the browser at 1366×768, 1280×800 and ~375px. The badge in the bottom-right corner of this page reports your current viewport.

  1. Open every modal: title, close, first label, first input and footer buttons aligned and one family. Header and footer stay visible; only the body scrolls.
  2. Select versus text input versus filter dropdown toggle: same height and border.
  3. Trigger a validation error: the message sits under its field and does not overlap or shove the next row off-grid.
  4. Table: header, first-row actions, pagination, empty state. Filter the table to zero rows — DataTables must render the card empty state, never its raw “No matching records found”. Set language.zeroRecords and language.emptyTable on every table. Confirm pagination sits in the card footer and does not scroll sideways with the table (the dom string owns .table-responsive).
  5. Tab through header actions, filters, table buttons and the modal. The focus ring is always visible.
  6. Hover: nothing jumps, no cyan btn-info beside primary blue.
  7. Form grid: no 1+3 leftover column, no control wrapping inside its cell, no horizontal page scroll.
  8. Related pages that share the modal or section still match.
  9. Legacy JS still binds: the shim adds data-bs-toggle and keeps data-toggle, so delegated selectors such as $(document).on('shown.bs.tab', 'a[data-toggle="tab"]', …) (pages/ptw_form.html) keep matching. Grep the page for [data-toggle= selectors and click each control once to confirm the handler fires exactly once — never twice, and never open-then-instantly-closed.
  10. Workbook vs form: a dense .enr-grid / .bei-table cell is 32px; every filter, modal field and gems-form-grid control is still 38px. The workbook empty-state sentence wraps inside the scroller — it must not become one nowrap line at 375px.
  11. View source: no mdb.min.css, bootstrap.min.css, style.css, gems2-ui.css, popper.min.js or mdb*.js.
  12. Console is clean — no shim errors, no missing-plugin TypeErrors.
