4. Badges — one status vocabulary

Sentence case, one radius, semantic colour. Uppercase only when the status string is genuinely an acronym (PTW, KPA). Counts and “showing 1 of 24” use muted text, not a second pill language.

8. Arrangement demo 2 — modals on a short laptop

Widths only: sm 480, md 640, lg 800. Create/edit defaults to md. Anything taller than ~5 fields uses modal-dialog-scrollable, never modal-dialog-centered: on a 768px-tall screen the footer must stay visible while only the body scrolls. No 960px dialog unless it contains a table.

10. Close-up QA — run this on every converted page

A screenshot of the whole page is not “done”. Check each screen in the browser at 1366×768, 1280×800 and ~375px. The badge in the bottom-right corner of this page reports your current viewport.

  1. Open every modal: title, close, first label, first input and footer buttons aligned and one family. Header and footer stay visible; only the body scrolls.
  2. Select versus text input: same height and border.
  3. Trigger a validation error: the message sits under its field and does not overlap or shove the next row off-grid.
  4. Table: header, first-row actions, pagination, empty state. Filter the table to zero rows — DataTables must render the card empty state, never its raw “No matching records found”. Set language.zeroRecords and language.emptyTable on every table.
  5. Tab through header actions, filters, table buttons and the modal. The focus ring is always visible.
  6. Hover: nothing jumps, no cyan btn-info beside primary blue.
  7. Form grid: no 1+3 leftover column, no control wrapping inside its cell, no horizontal page scroll.
  8. Related pages that share the modal or section still match.
  9. Legacy JS still binds: the shim adds data-bs-toggle and keeps data-toggle, so delegated selectors such as $(document).on('shown.bs.tab', 'a[data-toggle="tab"]', …) (pages/ptw_form.html) keep matching. Grep the page for [data-toggle= selectors and click each control once to confirm the handler fires exactly once — never twice, and never open-then-instantly-closed.
  10. View source: no mdb.min.css, bootstrap.min.css, style.css, gems2-ui.css, popper.min.js or mdb*.js.
  11. Console is clean — no shim errors, no missing-plugin TypeErrors.
