Integration Instructions
How to integrate PTW view mode into your dashboard:
  1. URL Parameters: Use the following format: ptw_form.html?mode=view&role={ROLE}&id={PTW_ID}
  2. Supported Roles:
    • supervisor - PTW Supervisor Review
    • she - Safety, Health & Environment Review
    • facility_manager - Facility Manager Final Approval
  3. Modal Integration: Load the URL in an iframe within a Bootstrap modal
  4. API Endpoints:
    • GET api/ptw.php?action=get&id={PTW_ID} - Load PTW data
    • POST api/ptw_approval.php - Submit approval/rejection
