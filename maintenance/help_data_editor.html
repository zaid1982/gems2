📊 Interactive Data Editor

Complete Guide to Database Record Management

📋 Overview

The Interactive Data Editor is a powerful web-based tool that allows you to view, edit, and manage database records with a spreadsheet-like interface. It provides safe and efficient ways to update multiple records without writing SQL queries.

🎯 Perfect For

  • Quick data corrections and updates
  • Bulk record modifications
  • Data entry and maintenance tasks
  • Non-technical users who need database access

🚀 Getting Started

  1. Select a Table
    Choose a table from the dropdown menu. Tables show their current record count for reference.
  2. Browse Records
    Records are displayed in a paginated table with all columns visible. Use pagination controls to navigate through large datasets.
  3. Edit Data
    Click on any editable cell (non-primary key columns) to start editing. Changes are tracked automatically.
  4. Save Changes
    Use the "Save All" button to commit all pending changes to the database at once.

⭐ Key Features

🔒 Safe Editing

Primary keys and auto-increment columns are protected from editing. Only valid data modifications are allowed.

📄 Pagination

Handle large tables efficiently with adjustable page sizes (10, 25, 50, 100 records per page).

🔍 Search Functionality

Search across all text columns to quickly find specific records you need to edit.

📝 Change Tracking

Visual indicators show which records have been modified. Review all changes before saving.

💾 Batch Updates

Make multiple changes across different records and save them all in a single transaction.

🔄 Real-time Status

Live status updates show connection status, current actions, and change summaries.

✏️ Editing Guide

Cell Editing

  • Click to Edit: Click on any editable cell to start editing
  • Visual Feedback: Cells turn yellow while editing, green when changed
  • Data Types: System automatically validates data types
  • NULL Values: Clear a cell completely to set it to NULL

Action Shortcut Description

Cancel Edit Escape Cancel changes and revert to original value

Change Management

📝 Pending Changes Panel

The changes summary panel shows:

  • Which rows have been modified
  • Original vs. new values for each change
  • Total number of pending changes
  • Options to save all or discard changes

🛡️ Safety Features

⚠️ Important Safety Measures

  • Protected Columns: Primary keys and auto-increment columns cannot be edited
  • Data Validation: Input is validated against column data types
  • Transaction Safety: All changes are applied in a single database transaction
  • Rollback Support: Failed operations automatically rollback all changes

Column Types & Restrictions

  • 🔑 Primary Key: Cannot be edited (marked with key icon)
  • 🔢 Auto Increment: System-generated, cannot be modified
  • ✏️ Regular Columns: Fully editable with data type validation
  • 🔗 Foreign Keys: Editable but must reference valid records

🔧 Troubleshooting

Common Issues

❌ "Cannot edit this cell"

This usually means the column is a primary key or auto-increment field. These are protected for data integrity.

❌ "Changes failed to save"

Check for:

  • Data type mismatches
  • Required fields left empty
  • Foreign key constraint violations
  • Network connectivity issues

❌ "Table not loading"

Possible causes:

  • Database connection issues
  • Table permissions
  • Very large tables (try searching to filter)

Recovery Options

  • Reload Table: Refreshes data and discards unsaved changes
  • Discard Changes: Removes all pending modifications
  • Navigate Away: Changes are lost when leaving the page
